Политика конфиденциальности Agent OS

Дата вступления в силу: 4 ноября 2026 г.

Главный принцип: Agent OS обрабатывает данные локально на вашем устройстве. Мы не собираем и не передаём ваши личные данные на какие-либо серверы разработчика.

1. Какие данные обрабатываются

  • Голосовые команды. Распознавание речи выполняется системным сервисом Android на устройстве. Записи голоса не сохраняются и не передаются разработчику.
  • История команд и быстрые действия. Хранятся только в памяти вашего телефона (локальные файлы и настройки приложения).
  • Контакты, SMS, звонки. Используются только для выполнения ваших прямых команд (позвонить, написать). Никакой передачи третьим лицам.

2. Разрешения и зачем они нужны

  • Микрофон — распознавание голосовых команд.
  • Уведомления — постоянный быстрый доступ к ассистенту.
  • Таймер/будильник — выполнение команды «таймер».
  • Контакты / телефон / SMS — выполнение команд «позвони», «напиши» (только по вашему запросу).

3. Передача данных третьим лицам

Данные не передаются. Распознавание речи и синтез голоса используют системные компоненты Android, установленные на вашем устройстве. В будущих версиях может появиться реклама; в этом случае политика будет обновлена с указанием рекламной сети.

4. Хранение и удаление

Все данные хранятся локально. Вы можете удалить историю и быстрые действия внутри приложения или полностью удалить приложение — все данные будут стёрты.

5. Дети

Приложение не предназначено для детей младше 13 лет и сознательно не собирает их данные.

6. Изменения политики

При существенных изменениях мы обновим дату вверху этой страницы.
